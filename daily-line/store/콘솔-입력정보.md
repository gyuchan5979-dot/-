# 앱인토스 콘솔 입력 정보 — 매일 한 줄

콘솔(https://apps-in-toss.toss.im)에서 그대로 복사해 넣으면 돼요.

## 앱 등록

| 항목 | 입력값 |
|---|---|
| 앱 이름 (국문) | 매일 한 줄 (이미 있으면: 하루 한 줄, 오늘의 한 줄) |
| 앱 이름 (영문) | One Line a Day |
| appName | `daily-line` ← **정확히 이대로** (코드의 `apps-in-toss.config.ts`와 같아야 해요. 이미 쓰이고 있으면 알려주세요, 코드를 바꿀게요) |
| 앱 유형 | 비게임 |

## 기본 정보

**부제**

```
하루 한 문장, 마음에 남는 고전 글귀
```

**상세 설명**

```
매일 하나씩, 마음에 오래 남는 문장을 건네드려요.

윤동주, 김소월, 한용운, 이육사 같은 우리 시인의 시 구절부터 『어린 왕자』, 『데미안』, 『명상록』, 『논어』까지. 오랫동안 사랑받아 온 고전에서 고른 한 줄과 함께, 오늘 하루를 위한 짧은 생각 한마디를 덧붙였어요.

· 오늘의 한 줄: 하루에 한 문장이 열려요. 내일은 새로운 문장이 기다려요.
· 연속 읽기: 매일 들를수록 기록이 쌓여요. 🔥 7일째, 30일째에 도전해 보세요.
· 지난 한 줄: 놓친 날의 문장도 다시 열어 볼 수 있어요.
· 간직함: 마음에 드는 문장은 ❤️ 간직해 두고 언제든 다시 꺼내 보세요.
· 공유와 이미지 저장: 친구에게 오늘의 한 줄을 보내거나, 예쁜 카드 이미지로 저장해 SNS에 올릴 수 있어요.

모든 문장은 저작권 보호기간이 끝난 작품에서 골랐고, 외국 작품은 원문에서 새로 옮겼어요.
```

**사용 연령**: 만 19세 이상 (현재 앱인토스 기준)

**고객문의 이메일**: 본인 이메일 입력

## 카테고리 및 노출

- 카테고리: 라이프스타일(또는 교육/도서)에 가장 가까운 항목
- 앱 로고: `store/logo-600.png` (600×600)
- 스크린샷(세로 4장): `store/screenshot-1-today.png`, `store/screenshot-2-past.png`, `store/screenshot-3-detail.png`, `store/screenshot-4-saved.png` (636×1048)

## 앱 번들

`npm run build`로 만든 `daily-line.ait`를 올리고, **토스앱 테스트를 한 번 이상** 한 뒤 검토를 요청해요.

## 광고 (출시 후 업데이트)

콘솔 > 인앱 광고 > 광고 그룹에서 두 개를 만들어 ID를 알려주세요.

1. **배너** (지난 한 줄 목록 아래) → `.env.production`의 `VITE_AD_BANNER_ID`
2. **보상형** (놓친 날 문장 열기) → `VITE_AD_REWARD_ID`

ID가 비어 있으면 광고 없이, 놓친 날 문장도 그냥 열려요.

## 저작권 근거 (문의 대응용)

- 한국 저작권법: 1962년 이전에 사망한 작가의 작품은 보호기간이 끝났어요. (1963년 이후 사망 작가는 사후 70년 보호 → 넣지 않음)
- 수록 작가와 사망 연도는 `src/data/lines.ts`의 `AUTHORS`에 있고, 테스트가 1962년 이전인지 확인해요.
- 외국 작품은 기존 번역서를 쓰지 않고 원문에서 새로 옮겼어요.
- '오늘의 생각' 문구는 직접 쓴 글이에요.
